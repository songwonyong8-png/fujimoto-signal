# Fujimoto Signal v1.0

개인용 아이폰 PWA 매매신호등. RSI(14), SMA20 이격도, MACD(12,26,9), 거래량/20일 평균, 20일 저점 지지로 매수 반등 신호를 계산합니다. 후지모토 시게루의 공식 규칙을 복제한 것이 아니라 과매도/반등 철학을 참고한 **자체 가설 전략**입니다. 투자 조언이나 매매 성과 보장이 아닙니다.

## 시작하기

1. 이 ZIP을 압축 해제하고 GitHub에 새 저장소를 만든 뒤 파일 전체(숨김 `.github` 폴더 포함)를 업로드합니다.
2. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**를 선택합니다.
3. **Actions → Daily OHLCV update → Run workflow**를 한 번 실행합니다. Actions 쓰기 권한이 차단된 경우 Settings → Actions → General → Workflow permissions에서 Read and write permissions를 허용해야 합니다.
4. 몇 분 뒤 `https://사용자명.github.io/저장소명/`으로 접속합니다. Safari 공유 버튼 → **홈 화면에 추가**를 누릅니다.
5. 자동 업데이트는 평일 23:30 UTC(한국 08:30)에 예약됩니다. 미국 서머타임/휴장일/데이터 제공 지연에 따라 최신 종가가 아닐 수 있습니다. 데이터가 7일 넘으면 신호를 보류합니다.

GitHub Pages의 정적 웹사이트는 공개 저장소에서 공개될 수 있습니다. 개인 보유정보, API 키를 넣지 마세요. yfinance/Yahoo 데이터는 비공식·비상업적 사용 제약, 지연, 결측 가능성이 있으므로 실제 주문 전 증권사 종가와 대조하세요. GitHub Actions 예약 실행은 지연되거나 건너뛸 수 있습니다.

## 로컬 테스트

`python -m http.server 8000` 후 `http://localhost:8000`에 접속합니다. 초기 상태는 **데이터 없음**이 정상입니다. `python -m pip install yfinance pandas && python update_data.py`를 실행하거나 CSV를 업로드하세요. CSV 필수 헤더: `Date,Open,High,Low,Close,Volume` (ISO 날짜, 오름차순 아니어도 됨). CSV 업로드는 현재 세션에서만 유지됩니다.

## 신호 규칙

- RSI는 Wilder 방식, 이격도=(종가/SMA20-1)*100, MACD 히스토그램은 EMA(12)-EMA(26)와 시그널 EMA(9)의 차이.
- 초록: RSI 30~48, 이격도 -0%~-무한(0 이하), MACD 히스토그램 전일 대비 개선, 종가 전일 대비 상승, 최근 20거래일 최저가 미이탈, 점수 65 이상.
- 노랑: 과매도(RSI<=35 및 이격도<=-5%) 또는 부분 반전/점수 45 이상, 지지선 이탈은 제외.
- 빨강: 그 외 또는 20일 지지선 이탈. 빨강은 **즉시 매도 명령이 아니라 신규매수 주의**.
- 지지선: 직전 20개 봉의 최저가. 단순한 참고값으로 정교한 매물대/추세선이 아닙니다.
- 데이터 부족(60일 미만)·7일 초과 시 신호를 보류합니다. 실적/퀀트/기관 수급은 v1에 포함되지 않습니다.

## 제약과 다음 개선

가격과 거래량은 일봉 데이터 기준, 데이터 소스는 yfinance. 주식분할 전후 시계열을 별도로 보정하지 않아 분할 이벤트 시 RSI/이격도가 왜곡될 수 있습니다. DRAM의 상품 이력에 따라 최소 60일 요건을 만족하지 못할 수 있습니다. 자동 갱신 실패 시 이전 JSON이 남아도 날짜가 오래되면 신호 보류됩니다. v2: 거래일 달력 기반 신선도 판정, 분할 조정 OHLCV, 백테스트(거래 비용/슬리피지/생존 편향), 알림, 펀더멘털, 포트폴리오 연동.
