# Fujimoto Signal F9-A — 내 보유 종목 중심 201종목 매매신호등

기존 아이폰 GitHub Pages 매매신호등을 **실제 사용자가 직접 입력한 보유정보** 중심으로 개편한 파일입니다.

## 화면 기능

- 코스피 시가총액 상위 100개(2026-10-25 F9 고정 스냅샷), 나스닥100 구성종목 상위 100개, 별도 관심 DRAM ETF **총 201개** 종목을 목록으로 표시합니다.
- **미보유:** 매수 1차 RSI 과매도 반등 신호가 있으면 `1차 매수 후보`; 없으면 `관망`.
- **보유:** 사용자가 체크한 단계의 매도 조건이 발생하면 `매도 확인`; 없으면 `보유 · 유지`.
- 전체/미보유/내 보유/매수 후보/매도 후보 탭, 시장 탭, 검색을 제공합니다.
- 종목을 눌러 **수량, 평균매수가, 보유 단계(1·2·3차 복수 선택)**를 기록할 수 있습니다.
- 매수 기록을 추가하면 **(기존 수량 × 기존 평균단가 + 매수 수량 × 체결 단가) ÷ 신규 총수량**으로 평균단가를 갱신합니다.
- 매도 기록을 추가하면 **보유 수량만 감소**하며, 남은 물량의 평균매수가는 유지됩니다. 수수료·세금을 제외한 해당 거래의 추정 실현손익을 안내합니다.
- 손익은 마지막 확인된 종가로 계산합니다. 원화 주식과 달러 주식을 서로 합산하지 않습니다.
- 보유정보는 **현재 브라우저/홈 화면 웹앱 로컬 저장소(localStorage)**에만 저장됩니다. GitHub에 업로드하지 않습니다. 백업/복원 JSON 제공.

## 매매 신호: 기존 F9-A 규칙 고정

| 물량 | 매수 신호 | 매도 신호 |
|---|---|---|
| 1차 · 1/9 | RSI(14), 최근 5일 과매도(30 이하) 이후 RSI 30~48에서 전일 대비 종가 상승 | RSI 30 이하 재하락 |
| 2차 · 2/9 | 1차 매수 이후 MACD(12,26,9) 골든크로스 | MACD 데드크로스 |
| 3차 · 6/9 | 2차 매수 이후 일목균형표 엄격 상승 돌파 | **A형: 종가 구름대 하단 이탈** |

전체 단계별 진입은 F9 백테스트에서 매수 순서 및 20거래일 기한을 사용합니다. 아이폰 화면에서 **미보유 종목의 매수 후보는 1차 RSI 신호만** 자동으로 표시합니다. 보유종목의 추가 매수 신호는 상세 화면에 지표 조건 충족 여부로 표시되지만, 사용자의 실제 진입일·매수 단계 이력과 결합한 추가 매수 주문 자격을 자동 확정하지 않습니다. **실제 보유한 단계는 사용자가 정확히 체크**해야 하며, 단계별 수량 자동 배분이나 자동 주문은 지원하지 않습니다.

공개 신호는 GitHub Actions의 `update_screener.py`가 **F9 엔진과 동일한 `backtest_f_v6.indicators` 계산 결과**에서 생성합니다. 당일 확정 일봉이 아닌 장중 봉은 배제합니다. 최신 데이터가 아닌 종목은 매수/매도 신호를 보류합니다.

## 파일 배치

```text
index.html                   ← 모바일 전체 종목 화면 (교체)
app.js                       ← 내 보유·검색·매매·로컬 저장 관리 (교체)
sw.js                        ← 서비스워커 업데이트 (교체)
manifest.webmanifest         ← 홈 화면 앱 이름 (교체)
update_screener.py           ← 201종목 신호 계산 (신규)
test_screener_f9a.py         ← 신호 계산 테스트 (신규)
data/screener_f9a.json       ← 최초 목록; Actions가 실제 신호로 갱신 (신규)
.github/workflows/daily.yml ← 201종목 일봉 갱신 작업 (교체)
README_PORTFOLIO_V10.md     ← 이 파일 (신규)
```

원래 저장소의 `universe_f9_snapshot.csv`, `update_data.py`, `signal_snapshot.py`, `test_signal_snapshot.py`, `backtest_f_v9.py`, `backtest_f_v6.py`와 백테스트 기존 의존 파일은 **삭제하거나 수정하지 않습니다**.

## GitHub 설치

1. ZIP을 아이폰 파일 앱에서 압축 해제합니다.
2. 위 파일 가운데 `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, `update_screener.py`, `test_screener_f9a.py`, `README_PORTFOLIO_V10.md` 7개를 저장소 **main 최상위 폴더**에 업로드/덮어씁니다.
3. `data/screener_f9a.json`을 **data 폴더**에 업로드합니다.
4. `.github/workflows/daily.yml` 파일을 **.github/workflows 폴더**에 업로드/덮어씁니다.
5. GitHub Actions → **Daily F9-A 200-stock iPhone Screener** → **Run workflow** → `main` → Run workflow를 누릅니다.
6. 작업이 성공하면 동일 GitHub Pages 주소에서 새 화면을 엽니다. 아이폰 홈 화면 기존 앱은 완전히 닫았다가 다시 실행하세요.

이 YAML은 일일 예약 실행과 수동 실행만 사용합니다. 이전처럼 `push` 이벤트로 동시에 실행되지 않아, 이미 한 번 발생했던 Git rebase 충돌 가능성을 낮춥니다. 하지만 사용자가 동시에 다른 워크플로/브랜치에서 데이터를 수정하면 여전히 Git 저장 충돌이 발생할 수 있습니다.

## 주의사항

- **실시간 호가/증권사 체결 연동이 아닙니다.** 종가 확정 뒤 다음 거래일 시가에 참고할 신호만 표시합니다.
- GitHub Pages가 사용하는 공개 데이터에는 **사용자 보유 종목·수량·평균단가를 절대로 기록하지 마세요.** 브라우저에만 입력하세요.
- Safari와 홈 화면에 추가한 웹앱은 로컬 데이터 저장공간이 분리되거나 Safari 데이터 삭제 시 소실될 수 있습니다. 반드시 백업하십시오.
- 종목 목록은 2026-10-25 순위를 고정한 연구용 목록이며 현재의 실시간 시가총액 순위를 뜻하지 않습니다. 신규 상장/결측 종목이 있으면 신호를 보류합니다.
- 자동 다운로드는 Yahoo Finance/yfinance를 이용합니다. 데이터 제한·오류가 있으면 누락 종목이 발생하며, 201개 모두 실시간으로 제공된다고 보장하지 않습니다.
- 평균매수가 기준 평가손익은 수수료/세금/환율/배당/자본 이벤트를 별도로 반영하지 않으며 실제 계좌 잔고와 다를 수 있습니다.
